# Diabetes Progression Prediction Using Wearable IoT Health Data

## Project Overview

This final-year project investigates the application of machine learning and data analytics to study and predict diabetes progression using health indicators collected through wearable IoT devices.

## Project Objective

The objective is to explore the potential of wearable health technologies and artificial intelligence to support continuous health monitoring, early risk identification, and data-driven healthcare decision-making.

## Key Features

- Health data preprocessing and cleaning
- Exploratory data analysis
- Patient-level feature engineering
- Machine learning model development
- Predictive performance evaluation
- Model comparison
- Interactive Power BI reporting
